# 🐝 Вулик — сайт по Bee Swarm Simulator

Сайт: https://uyli228.github.io/bss-site/

## Як редагувати

1. Відкрий сайт і натисни жовтий **олівець** справа внизу.
2. Встав GitHub-токен (створити: https://github.com/settings/tokens/new?scopes=public_repo&description=bss-site-editor).
3. Редагуй прямо на сторінці:
   - **+ Додати категорію / підкатегорію** — пунктирні картки;
   - на кожній картці й блоці: ↑ ↓ (порядок), ✎ (редагувати), ✕ (видалити);
   - у підкатегорії внизу — **Додати блок**: текст, картинка, картки з картинками, таблиця, посилання.
4. Натисни **Зберегти** внизу. Для всіх відвідувачів зміни з'являться за 1–2 хвилини.

Картинки завантажуються одразу при виборі файлу (великі автоматично стискаються).

## Як це влаштовано

- `content.json` — весь вміст сайту (категорії → підкатегорії → блоки).
- `uploads/` — картинки.
- `index.html`, `assets/app.js`, `assets/style.css` — сам сайт і редактор.

## Як закрити редагування

Видали кнопку-олівець (`data-fab`) з `index.html` або просто попроси Claude. Токен видаляється тут: https://github.com/settings/tokens
